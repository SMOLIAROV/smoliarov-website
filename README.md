## About

SMOLIAROV Personal Website is a personal website built to showcase my services, projects and technical expertise.

The project is focused on a clean interface, responsive design, performance and maintainable frontend architecture.

## Development

Configure the environment in `.env` and run:

```bash
npm install
npm run server
```
